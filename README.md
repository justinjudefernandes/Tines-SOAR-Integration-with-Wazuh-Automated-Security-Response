# Tines-SOAR-Integration-with-Wazuh-Automated-Security-Response
Integrated Wazuh with Tines SOAR to automate security alert handling, threat intelligence enrichment, Slack notifications, analyst approval, and response actions. Built an end-to-end workflow using AbuseIPDB, VirusTotal, Wazuh API, and Active Response to detect, investigate, and contain suspicious activity.
